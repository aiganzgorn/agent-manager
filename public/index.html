Правки сохраняются прямо в файлы, которые читает opencode. Перезапуск не нужен: он следит за файлами. Если в TUI что-то не подхватилось — /reload.

Агент

Строчные латинские буквы, цифры, - _ .. Станет именем файла и id агента.
Для субагента это единственное, что видит основная модель при выборе, кого запустить. Пиши предметно: что делает и по какой просьбе.
У нового агента по умолчанию primary. Субагент живёт в дочерней сессии со своим контекстом.
Формат provider/model, можно вариант: anthropic/claude-sonnet-5-5#high. Пусто — субагент наследует модель родителя.
Правила проверяются по порядку, побеждает последнее совпавшее. Сначала широкий запрет, следом исключения. Экшены: shell, edit, read, glob, grep, webfetch, websearch, skill, subagent.
В markdown-агенте это просто тело файла ниже ---. Непустой промпт заменяет базовый промпт провайдера.

            Куда сохраняется
            
Глобально: ~/.config/opencode/agents/имя.md — работает во всех проектах.

            
Проект: <проект>/.opencode/agents/имя.md — только в этом проекте.

            
Проектный конфиг перекрывает глобальный; глобальный — ниже по приоритету.

          


          

            Когда перезагружать
            
Не нужно. opencode следит за файлами конфигурации и сам перечитывает агентов после сохранения.

            
Если в TUI всё ещё старый агент — набери /reload. Перезапуск сервиса нужен только если он завис.

          


          

            Как позвать субагента
            
Из основной сессии: «используй субагента имя для …». Модель видит список субагентов, их id и description.

            
Разрешить/запретить запуск можно правом subagent с ресурсом — id агента.

          


          

            Про V1-поля
            
Если в файле есть permission, tools, temperature, maxSteps — это старый формат. Приложение их не трогает и сохраняет дословно, но V2 их не рекомендует: права задавай через permissions.

          


          

            Встроенные агенты
            
build, plan, general, explore встроены. Их можно переопределить, описав агента с тем же id в opencode.json — файлы рядом с ними не спорят.
