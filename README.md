# agent-manager

Локальный браузерный менеджер агентов и субагентов opencode V2. Показывает, кто
у тебя определён, даёт править и создавать агентов, и пишет прямо в те файлы,
которые читает сам opencode — конвертировать и перезапускать ничего не нужно.

## Запуск

```sh
cd agent-manager
node server.mjs                    # скан текущей папки
node server.mjs ~/workspace/ai_projects
PORT=4800 NO_OPEN=1 node server.mjs
```

Открывается `http://127.0.0.1:4737/`. Зависимостей нет, обычный `node` (проверено
на 14 и 24). Папка проекта-сканера переключается прямо в интерфейсе.

## Что читает и куда пишет

| Скоуп | Markdown-агенты | Создание идёт в |
| --- | --- | --- |
| Глобально | `~/.config/opencode/agents/*.md`, плюс старый `~/.config/opencode/agent/*.md` | `~/.config/opencode/agents/` |
| Проект | `<проект>/.opencode/agents/*.md`, плюс `.opencode/agent/*.md` | `<проект>/.opencode/agents/` |

Проекты ищутся в корне на один уровень вглубь: папка считается проектом, если в ней
есть `.opencode/` или `opencode.json(c)`.

Агенты, заданные внутри `opencode.json` (ключ `agents`), показываются только для
чтения: переписывать JSONC с комментариями этот редактор не берётся. Файлы в
старом формате V1 (`permission`, `tools`, `temperature`, `maxSteps`) открываются и
сохраняются с этими полями дословно — ничего не теряется, но интерфейс помечает
их как V1 и предлагает права через `permissions`.

## Поля

`description`, `mode` (`primary` / `subagent` / `all`), `model`
(`provider/model#variant`), `permissions` (список `action` / `resource` / `effect`),
`steps`, `hidden`, `color`, и тело файла — системный промпт.

## Применение правок

opencode следит за файлами конфигурации и перечитывает агентов после сохранения —
перезапуск не нужен. Если в TUI всё ещё виден старый агент, набери `/reload`.
Перезапуск сервиса (`opencode service restart`) нужен только если сервис завис.

## Проверки

```sh
node frontmatter.test.mjs     # разбор/сборка frontmatter, сохранение V1-полей
node server.mjs &             # затем:
node smoke-test.mjs           # создание/сохранение через HTTP API на временной папке
```

## Чего нет намеренно

Удаления и переименования агентов, редактирования `opencode.json`, списка моделей
из конфига. Это добавляется по запросу.
